# TPI-PROGRAMACION

# Trabajo Práctico Integrador - Gestión de Datos de Países en Python

## Descripción

Este proyecto fue desarrollado como Trabajo Práctico Integrador de la materia Programación 1 de la Tecnicatura Universitaria en Programación a Distancia (UTN).

La aplicación permite gestionar información de países almacenada en un archivo CSV, implementando operaciones de carga, actualización, búsqueda, filtrado, ordenamiento y generación de estadísticas utilizando listas, diccionarios, funciones y archivos. El desarrollo se realizó siguiendo criterios de modularización y validación de datos solicitados en la consigna.

## Objetivo

Desarrollar una aplicación en Python capaz de administrar información sobre países, aplicando estructuras de datos, funciones, filtrados, ordenamientos y estadísticas básicas a partir de un conjunto de datos almacenado en archivos CSV.

## Funcionalidades implementadas

El sistema ofrece un menú de opciones en consola que permite:

1. Agregar países.
2. Actualizar población y superficie de un país.
3. Buscar países por nombre (coincidencia parcial o exacta).
4. Filtrar países por continente, población o superficie.
5. Ordenar países por nombre, población o superficie.
6. Mostrar estadísticas:

    * País con mayor población.
    * País con menor población.
    * Promedio de población.
    * Promedio de superficie.
    * Cantidad de países por continente.

## Estructura del proyecto

El proyecto fue organizado de manera modular, separando las distintas responsabilidades en archivos independientes para facilitar el mantenimiento y la comprensión del código.

Los datos utilizados por el sistema se almacenan en un archivo CSV incluido en el repositorio.

## Requisitos

* Python 3.x

## Ejecución

Desde una terminal ubicada en la carpeta del proyecto:

```bash
python main.py
```
